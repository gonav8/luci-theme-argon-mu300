# Argon for MU300

This repository keeps the Argon theme's visual language and adds a small compatibility stylesheet for the MU300 LuCI application. It does not replace the plugin's pages, data collection, live polling, or controls. The stylesheet maps MU300's own cards, signal indicators, meters, and controls to Argon's primary color and light/dark surfaces.

## MU300 menu and dashboard

The **Status dashboard** and **Cellular** menus in the supplied reference are registered by the MU300 LuCI application, not by a theme. Install a compatible `luci-app-mu300` package on the router; LuCI will then populate its Cellular pages and the MU300 home dashboard with the device's actual live data. This theme styles that existing UI. It does not fabricate modem readings or add an empty menu when the application is absent.

The plugin source and packaging are maintained separately at [kanoqwq/mu300-linux](https://github.com/kanoqwq/mu300-linux). Follow that project's OpenWrt 25.12.x instructions and use a build compatible with your MU300 firmware.

## Build

Build this theme with the OpenWrt 25.12.x SDK for the router's target architecture. Package version: `2.5.0-1`.
